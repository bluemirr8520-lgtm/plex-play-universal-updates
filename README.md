# Plex Play Universal

Plex Play의 홈·라이브러리·상세 화면과 사용자 설정을 그대로 유지하면서,
Android 기본 디코더가 열지 못하는 영상·오디오를 로컬 범용 코덱으로 다시 재생하는
별도 Android 프로젝트입니다. 원본 `Plex Play`와 앱 ID 및 설정 저장소가 달라 두 앱을
같은 기기에 동시에 설치할 수 있습니다.

현재 개발·배포 대상은 Universal입니다. 기존 Plex Play는 더 이상 새 버전을 빌드하거나 배포하지 않습니다.

GitHub 배포 APK는 [최신 공개 릴리스](https://github.com/bluemirr8520-lgtm/plex-play-universal-updates/releases/latest)의 `PlexPlayUniversal.apk`를 사용합니다. GitHub 로그인 없이 다운로드할 수 있습니다. 로컬 `*-debug.apk` 테스트 파일과는 빌드 구성이 다르며, 배포 절차는 기존 고정 인증서가 일치하고 테스트·무결성 검사를 통과할 때만 새 버전을 게시합니다.

2026-09-30에 이전 배포 목록을 v1.0.31로 통합했습니다. 당시 릴리스의 첨부·설명은 로컬 백업으로 보존하고 Git 태그·소스 이력은 유지합니다. 빌드용 `libvlc-all-3.7.5.aar`는 계속 v1.0.31 릴리스에서 제공합니다. 최신 앱은 위 최신 릴리스 링크에서 받으세요. 자세한 과거 정리 범위는 [릴리스 정리 기록](RELEASE_CLEANUP_2026-09-30.md)을 참고하세요.

## 1.0.40 변경 사항

- 홈의 라이브러리별 최근 추가 시리즈는 포스터·제목을 유지하고 제목 아래에 `최신 · S2:E8 · 에피소드 제목`을 표시합니다. 서버에 가장 최근 추가된 에피소드 기준이며, 먼저 목록을 표시한 뒤 최대 3개의 백그라운드 조회로 채웁니다.
- 홈은 라이브러리별 조회가 끝나는 대로 표시합니다. 사용하지 않는 시청 완료·라이브러리별 이어보기의 홈 진입 조회를 없애고, 라이브러리에서는 전체 목록과 이어보기를 동시에 요청해 전체 목록을 먼저 사용하도록 합니다. 이미 읽은 홈과 최근 라이브러리 목록은 재사용하며 가나다순 정렬은 화면 스레드 밖에서 처리합니다.
- 관련 작품 조회에서 중복 상세 정보 요청과 불필요한 미디어·스트림 데이터를 줄입니다. 최대 3개씩 조회하고 먼저 찾은 작품부터 표시하며, 제한된 메모리 캐시로 반복 조회를 줄입니다.
- 관련 작품 조회 중에도 재생을 시작합니다. 재생을 누르면 선택적 조회와 그 연결을 취소하고 재생 준비를 우선합니다. 계정·화면 변경 이후의 오래된 결과를 반영하지 않으며, 시청 상태 변경과 새로고침 시 목록 캐시를 비웁니다.
- 영상 화질·디코더·사용자 자막·같은 폴더 이전/다음 규칙과 서버/rclone 설정은 유지합니다. 실제 서버·기기에서의 속도 및 화면 확인은 별도로 필요합니다.

## 1.0.39 변경 사항

- 원본·범용/VLC의 리모컨 길게 누르기 탐색은 목표 시간을 10초 단위로 누적하고, 손을 떼거나 마지막 입력 후 0.3초가 지나면 실제 탐색을 한 번 실행합니다. 반복 키마다 실제 탐색하던 부담을 줄입니다. 목표 시간은 화면 안내에 표시합니다.
- 짧은 스킵은 즉시 이동하고 이어보기 정확도는 유지합니다. 진행 막대가 선택되어 있을 때는 기존 진행 막대의 미리보기·탐색 동작을 사용합니다. 설정 열기, 다른 영상으로 이동, 재생 화면 닫기, 취소된 키 입력과 직접 탐색은 이전 대기 목표를 취소합니다.
- 영상 길이·경계·정수 오버플로와 누적 목표를 검증합니다. 기존 화질, 자막, 디코더와 네트워크 버퍼 값, 서버/rclone 설정은 변경하지 않았습니다. 캐시되지 않은 구간을 처음 읽는 다운로드 대기까지 없애는 기능은 아닙니다.

## 1.0.38 변경 사항

- 원본·VLC의 가로/세로 자막 내용과 스타일이 같으면 반복 레이아웃·그리기를 건너뜁니다. 가로 줄바꿈 계산도 내용·글꼴·크기·표시 폭이 같을 때 재사용하며 위치 이동은 즉시 반영합니다.
- VLC에서 실제 영상 프레임 속도(23.976/29.97 등)와 배속에 맞는 화면 주사율 힌트를 전달합니다. Android 11 이상에서 지원하며 Android 12 이상은 끊김 없는 주사율 전환만 요청합니다. 일시정지·종료 시 힌트를 해제하고 화면 생성 시 다시 적용합니다. 플랫폼이 최종 주사율을 선택합니다. [Android 프레임 속도 문서](https://developer.android.com/media/optimize/performance/frame-rate)
- VLC 자동 모드의 네트워크 버퍼를 일반 영상 3초, 4K 또는 50fps 이상 영상 6초로 확보합니다. 저메모리 기기는 최대 3초입니다. 시작·탐색 대기가 늘 수 있습니다.
- 기기 디코더 처리량 부족이나 영상 비트레이트보다 느린 서버·네트워크를 버퍼만으로 해결할 수는 없습니다. 실제 기기의 프레임 속도·장시간 재생은 별도 확인이 필요합니다.

## 1.0.37 변경 사항

- 범용/VLC 사용자 자막은 드래그 중의 좌표를 즉시 화면에 반영합니다. 손을 뗀 뒤에만 위치가 바뀌던 처리를 수정했습니다. 가로·세로쓰기 모두 같은 미리보기 좌표를 사용합니다.
- 이동 중에는 저장된 설정을 바꾸지 않아 터치 처리가 중단되지 않으며, 최종 위치만 드래그 종료 시 저장합니다. 제스처가 취소되면 미리보기를 버리고 기존 위치로 돌아갑니다.
- 기존 위치 범위·제스처 구역·자막 글꼴과 VLC 영상/오디오 디코더는 유지합니다. 이미지/원본 자막의 사용자 설정 제한은 기존과 같습니다.
- 연결된 휴대폰에 기존 앱을 삭제하지 않고 v1.0.37로 업데이트하여 설치 버전을 확인했습니다. GitHub 배포 파일은 업로드 후 다시 내려받아 무결성·서명·버전을 검증합니다. 실제 기기의 드래그 반응은 추가 확인이 필요합니다.

## 1.0.36 변경 사항

- VLC도 일반 재생과 동일한 Media3 재생 컨트롤을 사용합니다. 공통 제목 영역·닫기·화면 크기·설정 버튼, 중앙 이전/10초 뒤로/재생/10초 앞으로/다음 버튼과 진행 막대를 맞췄습니다. VLC 디코더·사용자 자막·화면 설정은 유지합니다.
- 검색·이어보기의 짧은 목록 때문에 같은 폴더의 다음 버튼이 비활성화될 수 있던 후보 수집을 보완했습니다. 서버 시리즈/라이브러리 목록을 페이지별로 확인하고, 파일 경로가 없는 후보는 제한된 동시 조회로 보완합니다.
- 영상은 먼저 시작하고 이전·다음 목록은 백그라운드에서 갱신합니다. 재생 종료·다른 영상·계정 전환 이후의 오래된 결과는 반영하지 않습니다.
- 실제 파일의 바로 위 폴더를 기준으로 제한합니다. 다른 폴더·하위 폴더·다른 라이브러리나 경로를 확인할 수 없는 영상으로 자동 이동하지 않습니다. 마지막 영상에서 처음으로 되돌아가지 않습니다.
- 실기 화면·리모컨과 사용자 서버 영상에서의 확인은 별도 필요합니다. GitHub 배포 파일은 업로드 후 다시 내려받아 무결성·서명·버전을 검증합니다. 휴대폰 설치는 이번 배포에 포함하지 않습니다.

## 1.0.35 변경 사항

- 범용/VLC 연결 오류 시 기존 디코더로 연결 복구를 먼저 시도합니다. 4K·크기 불명 영상과 이미 재생이 진행된 영상에는 오류만으로 소프트웨어 디코딩을 강제하지 않습니다. 수동 소프트웨어 선택은 유지합니다.
- 자동 모드에서 4K·50fps 이상 영상의 네트워크 버퍼를 5초로 늘립니다. 안정성 우선은 최대 8초, 저메모리 기기는 최대 3초로 제한하며 로컬 파일 버퍼는 별도로 유지합니다.
- 원본·범용 재생의 사용자 자막을 한 번 색인하고 자막 시작/종료 시점 사이에는 결과를 재사용합니다. 자막 없는 상태의 반복 조회도 생략합니다.
- 자동 해상도 저하·강제 색상 변경 없이 기존 자막 글꼴·세로쓰기·위치, 화면 설정, 시리즈 목록·컬렉션 기능을 유지합니다.
- 실제 기기의 4K 프레임 속도·발열·장시간 안정성은 별도 확인이 필요합니다. 버퍼 증가는 네트워크 여유를 위한 조정이며 재생 시작/탐색 대기가 늘 수 있습니다.

## 1.0.34 변경 사항

- 별도 ‘정보’ 버튼을 제거하고 시리즈·시즌의 포스터, 제목, 줄거리, 장르, 시청 상태를 에피소드 목록 위에 함께 표시합니다.
- 목록 상단에서 ‘시청 완료’와 ‘시청하지 않음’을 바로 적용합니다. 정보와 목록은 같은 화면에서 함께 스크롤되며 긴 줄거리만 펼쳐 볼 수 있습니다.
- 상세 정보는 목록 진입을 막지 않고 추가로 불러옵니다. 폴더·계정 이동이나 시청 상태 저장 전에 시작한 조회가 새 상태를 덮어쓰지 않도록 합니다.
- 전체 완료 표시 후 에피소드 배지를 같은 목록에서 갱신합니다. 검색 결과가 없어도 상단 정보는 유지하며 별도 창을 열지 않습니다.
- 단일 폴더 건너뛰기, 개별 영상 재생·이어보기 및 시리즈 컬렉션 규칙은 유지합니다.

## 1.0.33 변경 사항

- 시리즈·시즌·에피소드 폴더를 선택하면 중간 상세창의 ‘목록 보기’를 거치지 않고 목록을 바로 엽니다.
- 실제 시즌·폴더가 하나뿐이면 한 단계만 건너뛰어 내용을 표시합니다. 여러 폴더, 영상이 섞인 목록, 불명확한 응답은 그대로 유지합니다.
- 목록 상단 ‘정보’에서 시리즈 상세·시청 완료 표시를 사용할 수 있습니다. 뒤로는 실제 방문한 이전 목록으로 돌아갑니다.
- 개별 영상의 상세·재생·이어보기와 기존 시리즈 컬렉션 규칙은 유지합니다.

## 1.0.32 변경 사항

- 시리즈의 수동 ‘시청 완료’ 또는 전체 에피소드 시청 완료 확인 시 **시리즈 자체**에만 컬렉션을 적용합니다.
- 개별 에피소드·시즌의 자동·수동 완료는 시청 기록을 저장하고 부모 시리즈를 확인합니다. 미시청 에피소드가 남으면 컬렉션을 변경하지 않습니다.
- 개별 에피소드와 시즌에는 컬렉션을 쓰지 않습니다. 기존 에피소드 태그를 자동 삭제하거나 과거 기록을 일괄 처리하지 않습니다.
- 서버 집계가 늦으면 최대 3회 읽기로 확인합니다. 에피소드 완료만으로 다른 에피소드를 강제로 시청 완료 처리하지 않습니다.
- 영화의 기존 규칙, 일반/예외 컬렉션명, NO_META·기타 경로 규칙 및 공유 사용자 권한 처리를 유지합니다.
- 전체 시리즈의 모든 에피소드·파일 경로·라이브러리 연결을 검증하고 안전할 때만 기존 시리즈 컬렉션을 지정 이름 하나로 교체합니다.

## 1.0.31 변경 사항

- 라이브러리 상단 왼쪽에 아이콘과 글자가 함께 있는 ‘홈’ 버튼을 추가했습니다. 하위 폴더에서도 뒤로 버튼 옆에서 홈으로 이동할 수 있습니다.
- 홈 버튼은 목록 스크롤과 무관하게 상단에 유지하며 터치·리모컨 확인 버튼으로 선택합니다. 리모컨 포커스는 금색 배경과 흰 테두리로 표시합니다.
- 좁은 휴대폰에서는 라이브러리 검색창을 제목 아래 별도 줄에 배치합니다. OTT/큰 화면의 제목 옆 검색과 사이드바 홈은 유지합니다.
- 홈으로 이동할 때 검색 키보드를 닫습니다. 기존 홈 화면 새로고침, 자막·화면·컬렉션 설정은 유지합니다.

## 1.0.30 변경 사항

- 공유받은 서버로 로그인한 일반 사용자는 시청 완료를 저장한 뒤 컬렉션 편집을 건너뜁니다. 수동 완료와 자동 재생 완료에 같은 규칙을 적용합니다.
- 기존 로그인 정보에 서버 소유 여부가 없는 경우, 선택적 컬렉션 쓰기의 권한 거부(401/403)는 실패 안내를 표시하지 않습니다. 컬렉션 변경 성공으로 표시하지도 않습니다.
- 서버 소유자의 컬렉션 기능과 사용자 지정 KILL/123 이름·경로 규칙을 유지합니다. 시청 기록 저장 오류, 일반 서버 통신 오류와 컬렉션 결과 검증 실패는 숨기지 않습니다.
- 서버 소유 여부는 로그인 연결 정보에 저장하며 계정 전환·로그아웃 때 이전 값이 남지 않도록 합니다.

## 1.0.29 변경 사항

## 1.0.19 변경 사항 (이전 버전)

- 원본 품질의 TrueHD 오디오 파일은 기기의 기본 디코더 지원 표시와 관계없이 앱 내 LibVLC 재생을 우선합니다. 원본 영상과 기존 사용자 텍스트 자막·화면 설정을 유지하며, PotPlayer를 내장하거나 외부 재생기를 호출하는 방식이 아닙니다. 1080p·720p·480p를 선택하면 기존 Plex 품질 변환 경로를 유지합니다.
- VLC의 `재생 설정 → 오디오`에 `자동`, `호환 PCM`, `HDMI 패스스루`를 추가하고 앱별 `player_settings`에 저장합니다. 현재 연결 경로와 코덱·채널·샘플레이트 지원이 확인되는 HDMI 장치에서만 패스스루를 사용합니다.
- 지원이나 경로가 불명확한 경우, 1.0×가 아닌 배속, 실행 중 디지털 출력 실패에는 PCM으로 재생합니다. 일시적인 PCM 복구는 저장한 출력 모드와 기존 자막·화면 설정을 초기화하지 않습니다.
- API 29 미만은 PCM을 사용합니다. API 29–32는 다른 출력 장치가 없는 단일 HDMI 연결과 형식 지원이 확인될 때만 패스스루를 허용하며, API 33 이상도 현재 HDMI 경로와 형식 지원을 확인합니다. PCM 채널 출력은 기기에 따라 다르며 Atmos 객체 정보나 모든 TV·사운드바 지원을 보장하지 않습니다.

자동 테스트 161개와 연결된 SM-S918N의 TrueHD 스테레오·5.1 PCM 디코딩/외부 자막 기기 테스트 4개를 통과했습니다. 같은 서명으로 데이터 초기화 없이 1.0.19를 업데이트 설치했습니다. 실제 장편 4K 영상과 HDMI·Atmos 출력은 별도 확인이 필요합니다. 자세한 범위는 [1.0.19 검증 기록](BUILD_VERIFICATION_1.0.19.md)을 참고하세요. 로컬 설치 테스트용 파일명은 `PlexPlayUniversal-1.0.19-debug.apk`입니다.

## 1.0.16 변경 사항 (이전 버전)

## 1.0.15에서 유지되는 기능

- 이전화·다음화·자동 다음 재생을 실제 파일의 같은 상위 폴더 안으로 제한합니다.
- 지정한 라이브러리에서 영상 재생이 완료되면 기존 컬렉션을 제거하고 `KILL` 또는 경로 예외에 해당하는 `123` 하나만 저장합니다.
- 경로를 확인할 수 없거나 서버 편집 권한이 없으면 컬렉션을 변경하지 않고 안내합니다. 자세한 대상·예외 경로는 [사용 설명서](USER_GUIDE.md#재생-완료-시-자동-컬렉션-지정)에 있습니다.
- 재생 중 서버·계정이 바뀌거나 이전 재생 세션에서 뒤늦게 완료 이벤트가 발생해도 다른 영상의 완료·컬렉션을 변경하지 않도록 확인합니다.

## 재생 방식

1. 원본 품질의 TrueHD·DTS/DTS-HD·MLP·특수 PCM 등 로컬 디코딩이 필요한 오디오는 VLC 범용 코덱을 우선 사용합니다.
2. 그 외에는 기기에서 원본 재생 지원으로 확인된 영상은 Media3로, `원본 재생 지원 여부 확인 필요` 영상은 처음부터 VLC로 엽니다.
3. 지원 영상도 Media3 재생이 실패하면 현재 위치를 유지하고 VLC로 자동 전환합니다.
4. 1080p·720p·480p 품질을 직접 선택한 경우에는 Plex 변환 스트림을 우선합니다.

VLC 엔진은 다양한 컨테이너와 H.264, HEVC, AV1, VP9, MPEG-2, VC-1/WMV 계열 영상,
AAC, AC-3, E-AC-3, TrueHD, DTS, FLAC, Vorbis, Opus 계열 오디오를 폭넓게 처리합니다. 실제 재생
가능 여부는 파일 손상 여부, DRM, 기기 CPU·GPU 성능 및 오디오 출력 장치에도 영향을
받으므로 모든 파일의 재생을 절대 보장하지는 않습니다.

## 자막

- Media3 재생: 기존 자막 선택, 한국어 자동 선택, 가로·세로쓰기와 사용자 자막 설정 유지
- VLC 범용 재생: 기본 재생과 같은 `재생 설정 → 자막/속도/화면/오디오/품질/최적화/저장공간` 메뉴
- 자막 끔, 한국어 자동, 내장 트랙, Plex 외부 자막을 각각 선택하고 선택 상태 유지
- 외부·내장 텍스트 자막은 기본 재생과 같은 사용자 렌더러로 표시하여 a시네마B·M·L,
  사용자 TTF/OTF, 크기, 색, 배경, 외곽선, 가로·세로 자유 위치와 세로쓰기를 동일하게 적용
- Plex 추출이 실패한 내장 자막은 원본 파일에서 텍스트 트랙만 읽는 보조 경로로 다시 시도
- SRT·ASS·SSA·VTT·TTML·SMI와 UTF-8/UTF-16 텍스트 자막 읽기 지원
- Plex 외부 자막 응답이 중간에 끊겨도 수신한 텍스트를 보존하며, 압축 없는 연결과
  토큰 재시도로 외부 SRT·SMI 자막의 사용자 설정 적용 안정성 개선
- 자막 설정을 바꾸면 즉시 저장하고 현재 자막에 다시 적용하므로 캐시 삭제나 앱 재실행이
  필요 없음
- 사용자 렌더러 적용·준비 중·VLC 원본 제한 상태를 표시하고 실패 시 안전하게 전환
- PGS/VobSub 같은 이미지 자막과 자체 스타일을 포함한 일부 ASS 자막은 형식 특성상
  사용자 글꼴·색·세로쓰기 적용이 제한됨

## 범용 재생 기능

- 기본 재생과 같은 리모컨 컨트롤 탐색, 이전화·다음화, 좌우 길게 탐색과 미디어 키
- 재생 설정 톱니바퀴와 메뉴에 4dp 고대비 리모컨 하이라이트, 설정창 밖 포커스 차단
- 자막·고급 화면 슬라이더에서 좌우는 현재 값만 조절하고, 위아래는 이전·다음 항목 이동
- 이전 버전에서 남은 낮은 창 밝기를 한 번 100%로 정상화하고 이후 사용자 설정은 보존
- 오른쪽 볼륨, 왼쪽 밝기, 아래쪽 탐색, 위쪽 화면 크기 및 두 손가락 확대 제스처
- 화면 모드, 고급 화면 조정, 화면 설정 1·2·3 저장·불러오기와 기본값 복원
- 자동·안정성·균형·고성능 기기 최적화 모드와 실제 VLC 버퍼 설정 연동
- 네트워크 오류 2회 재연결 후 Plex 대체 재생 경로 순차 시도
- 오디오 자동·직접 선택, 한국어 우선 자막 자동 선택 및 사용자 자막 설정 유지

## 빌드

JDK 17과 Android SDK 36이 필요합니다.

정식 APK는 기존 서명 키를 보관한 GitHub Actions에서 빌드합니다. 로컬 정식 빌드는 `PLEX_RELEASE_KEYSTORE`, `PLEX_RELEASE_STORE_PASSWORD`, `PLEX_RELEASE_KEY_ALIAS`, `PLEX_RELEASE_KEY_PASSWORD` 설정이 필요합니다. 서명 정보가 없으면 정식 빌드를 중지합니다.

```powershell
.\gradlew.bat assembleRelease
```

소스에서 빌드하려면 [v1.0.31의 libvlc-all-3.7.5.aar](https://github.com/bluemirr8520-lgtm/plex-play-universal-updates/releases/download/v1.0.31/libvlc-all-3.7.5.aar)를 내려받아 `app/libs/`에 넣으세요. SHA-256은 `2c25507adb1260aa4d81aad8c2ce98765d98026b9381f49ea454d0b8092f21cb`입니다. GitHub Actions도 이 위치와 해시를 사용합니다. 일반 설치자는 AAR 파일을 받을 필요 없이 APK만 설치하면 됩니다.

범용 코덱은 APK 내부에 포함됩니다. 모든 ABI를 한 APK에
담기 때문에 기본 앱보다 APK가 큽니다. 실제 배포에서는 동일한 서명 키를 계속 보관해야
이후 버전을 덮어쓸 수 있습니다.

VLC/LibVLC의 출처와 라이선스 안내는 [Third-party notices](THIRD_PARTY_NOTICES.md)에
정리되어 있습니다.
